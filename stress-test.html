How Popstart Handles Scale

  • ▶ No component instances -- functions are found and called, not instantiated. Each widget is just DOM + attributes. Zero per-widget memory overhead from the framework.
  • ▶ No virtual DOM diffing -- direct DOM manipulation. When you click a button, Popstart finds the function, calls it, done. No reconciliation pass over a component tree.
  • ▶ No shadow trees -- light DOM everywhere. CSS applies naturally with zero encapsulation overhead. Selectors just work.
  • ▶ MutationObserver for dynamic content -- __.DOMWatcher rebinds events when new elements appear. Generate 5,000 widgets and they're all interactive immediately.
  • ▶ Promise chains are GC'd after execution -- no persistent state per widget. Each event creates a short-lived promise chain that resolves and is garbage collected.
  • ▶ Per-element debounce -- debounce timers are stored on the element itself, so rapid clicks on widget A never interfere with widget B. Set debounce="0" for instant response.
